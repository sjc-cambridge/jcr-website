Adding a new Society / editing an existing one

If you are part of a club or society that is not on here and would like to be featured, please send an email to the computing officer (computing@sjcjcr.com) titled New Society Request with the following:

  • Society Name
  • Desired category to be filed under
  • Short description (50-100 words)
  • An attached image (4:3 landscape aspect ratio works best)

The same goes if you want to update a description (say with new captains).
